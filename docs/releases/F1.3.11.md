# Firmware F1.3.11

F1.3.11 makes the virtual 65C02 much faster, adds a 16 MB RamWorks option
and makes the FPGA design smaller. It includes the F1.3.10 changes, which
had no release of their own.

## Changes

- **Faster virtual 65C02 (TURBO).**
  - The card reads code before the CPU asks for it, and does the operand
    bytes in the same step as the opcode.
  - Zero page and stack have their own fast store. The cache is two times
    larger and is emptied much less often.
  - On a cache miss the card also reads the next word, and it goes on
    reading while the program runs through code in order.
  - Writes to the memory switches (RAMRD, RAMWRT, ALTZP, the RamWorks bank)
    no longer wait for the 1 MHz bus.
  - Measured on a card: the Mandelbrot demo takes 31 s (F1.3.10: 60 s). The
    Doom demo in ONE//e mode runs at 15.4 frames per second (an early
    F1.3.11 development image: 5.2).
- **ONE//e mode.**
  - Disk II and SmartPort use private fast ports, and the card copies whole
    blocks into memory.
  - Video writes are no longer repeated on the Apple bus, which has no
    reader in this mode.
  - Fix: flicker of the NTSC legacy picture (from F1.3.10).
  - Fix: the SDD video stream now stops correctly.
- **RamWorks 16 MB.** The RAM tab has a new option, "RamWorks 16MB in place
  of 8MB".
- **Video.** The renderer core is faster: it sends only the picture rows
  that changed and has a fast loop for text and monochrome. This removes
  the flicker that programs with many video writes showed at full CPU
  speed. Fix: the colour of the monochrome tint.
- **Sound.** The tone controls have a stronger boost toward the end of
  their range and wider cut bands.
- **PC Transporter.** Fix: reads of Transporter RAM while the virtual
  65C02 is on.
- **Slowdown window.** The window after a slowdown access can be set to
  0 cycles, which switches it off.
- **Diagnostics.** The serial command `vtw perf` shows the speed of the
  virtual 65C02 and where its time goes.
- **Smaller FPGA design.** During this work the design went from 40,563
  LUTs to 35,546, about 12% less, though it has more functions. The
  sound chips, the audio mixing and the speech filters share logic or use
  the multiplier blocks of the FPGA.
- Phillip Allison is in the About credits.

## Limits

- The speed figures are for the named programs. A program that reads slot
  cards or the keyboard very often is limited by the 1 MHz bus. A2Desktop
  is such a program: it reads the mouse card all the time.
- IIgs support remains experimental and off by default, as in F1.3.9.
  [IIgs setup and safety notes](https://github.com/hasseily/appletini-one/blob/F1.3.11/README_IIGS_SAFETY.md)

## Build and validation

The FPGA image is that of the development image F1.3.11dev36, run
`20261128T155916Z-6683c931-full`: setup slack +0.214 ns, bus skew and route
checks passed. The FPGA sources of this release are the same as the sources
of that run.

- The image audit verifies the loaded ARM bytes, the FPGA configuration,
  the embedded CPU1 payload, the firmware version and the manifest.
- The TURBO simulation bench passes.
- F1.3.11dev36 was tested on a card with the Doom demo, the Mandelbrot demo
  and the TINY language model.
- The final F1.3.11 image was tested on a card, with the 16 MB RamWorks
  option and the slowdown window of 0 cycles.

## Update

Install `FIRMWARE.BIN` through the normal firmware updater, or use
**About > Check for updates** with working Ethernet and SD storage.
Golden Boot **B2.0.6** is unchanged. Cards already using B2.0.6 need only
the firmware update. [Update instructions](https://github.com/hasseily/appletini-one/blob/F1.3.11/README_BOOT_UPDATE.md)
