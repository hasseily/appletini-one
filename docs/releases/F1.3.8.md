# Firmware F1.3.8

F1.3.8 contains the changes of the development builds F1.3.8dev1 to
F1.3.8dev8, and the PC Transporter name change.

## Changes

- **Web browser support.** The card now does the heavy work for the
  TINIBROWSER web browser (Appletini Software):
  - It converts PNG, JPEG and GIF images to finished 1-bit pictures.
  - It filters each web page to a short page in ASCII, without `<head>`,
    scripts and styles, so that long modern pages show their text.
  - It turns each form into one link, for GET and POST.
  - It gives each image its display size from the page, from `width` and
    `height` attributes and from CSS, with up to three linked style sheets.
  [Protocol](https://github.com/hasseily/appletini-one/blob/F1.3.8/README_HTTP_SMARTPORT_PROTOCOL.md)
- **Faster downloads.** All HTTP clients (CoGS games, Apple programs, the
  updater) use one set of fast transfer settings: 8 KiB of socket memory,
  immediate TCP acknowledge, 4 KiB reads, a 128 KiB buffer and 32 KiB SD
  writes. The screen repaints 10 times each second during a transfer, and
  the card reuses the TLS session of the last request when the server
  permits it. The CoGS screen shows the download rate.
- **CoGS catalog.** The load shows a percentage. The page numbers of the
  game list show when the load is complete.
- **PC Transporter** is no longer named a test mode. Floppy drives are not
  supported: use the hard disk file.
  [Setup and limits](https://github.com/hasseily/appletini-one/blob/F1.3.8/README_PC_TRANSPORTER.md)
- **Video.** In the colour modes "PAL composite" and "PAL TV", three soft
  switches (`$C050`, `$C00F`, `$C00D`) changed one or two phases too early
  or too late in VIDSYNC. They now have their own phase table.
- **Speech.** The SSI-263 parameter table is the SSI-263A table again.
  Twelve phonemes become louder (L1, Z, J, SCH, V, F, THV, TH, M, N, NG,
  LB). A recording of two SSI 263 AP chips showed these values.
- **FPGA timing.** The build copies the registers that drive the two Apple
  direction pads. The direction pads no longer limit the timing.

## Limits

- The web services need TINIBROWSER from Appletini Software 1.3.8.
  JavaScript does not run, the card keeps no cookies, and WebP and SVG
  images do not show.
- The card filters a page and decodes an image in one step. During that
  step it does not serve SmartPort disk calls.
- The JPEG and GIF decoder (`stb_image`) is not hardened against malformed
  files from a web site.
- IIgs support remains experimental and off by default, as in F1.3.7.
  [IIgs setup and safety notes](https://github.com/hasseily/appletini-one/blob/F1.3.8/README_IIGS_SAFETY.md)

## Build and validation

The FPGA image is that of F1.3.8dev1, run
`20261120T190553Z-fea5c6e9-full`. Vitis rebuilt the platform, the FSBL and
both ARM cores from the matching XSA with the F1.3.8 version label.

- Setup WNS **+0.160 ns**, hold **+0.047 ns**, pulse width **+0.265 ns**.
- No failing endpoints. Route, bus skew, and checked constraint bounds
  pass, with zero missing constraint objects.
- The run used a +0.000 ns export gate. The package check requires
  +0.020 ns.
- The host tests of the changed network code pass: the HTTP engine, the SD
  download, the picture and page services and their protocol, the repaint
  limit, and the CoGS service and screen.
- Of the 62 host tests that read the files changed for dev3, 49 passed.
  The other 13 failed in the same way on an untouched copy of F1.3.7, or
  needed a lab TLS peer that was not running. The dev3 note lists them.
- The image audit verifies the loaded ARM bytes, the FPGA configuration,
  the embedded CPU1 payload, the firmware version and the manifest.

This note records no board test of the final image. The development notes
say the same for each of their images.

## Update

Install `FIRMWARE.BIN` through the normal firmware updater, or use
**About > Check for updates** with working Ethernet and SD storage.
Golden Boot **B2.0.6** is unchanged. Cards already using B2.0.6 need only
the firmware update. [Update instructions](https://github.com/hasseily/appletini-one/blob/F1.3.8/README_BOOT_UPDATE.md)
