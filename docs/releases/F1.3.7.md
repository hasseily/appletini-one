# Firmware F1.3.7

F1.3.7 contains the changes through the accepted F1.3.7dev20 firmware.

## Changes

- Browse and download 8-bit game disks from **Ethernet > CoGS games**.
  The catalog stays in memory until restart. Downloads go to
  `_software/CoGS`, with a new filename when a disk already exists.
- Add **PC Transporter (test)** in virtual slot 5, with shared RAM,
  Portware I/O, CGA video, USB keyboard input, 4 MiB EMS, and Standard or
  Maximum CPU resource use. Improve CGA capture, mode changes, blink,
  cursor display, and programs that reuse video RAM during scanout.
- Add an opt-in, experimental **IIgs physical-slot-3 profile** and native
  GS video capture. Host acceleration and memory replacement stay disabled
  in this profile.
- Allow one Phasor in logical slot 2 or slot 4. ROM 1 IIgs owners can keep
  slot 4 internal for the native mouse.
- Make SSI-263 transitioned pitch follow the SC-02 prototype circuit's
  rate and slope controls.
- Align both VSYNC edges with HSYNC assertion. Active NTSC 1080p keeps
  its 1126-line frame. A user confirmed that the sync fixes in dev19
  resolved their display problem.
- Reduce ONE//e type-ahead and held-key repeat backlogs, so programs that
  read keys slowly respond to new keys sooner.
- Return the actual byte count for supported SmartPort character reads.
- Wait for Ethernet before automatic update checks, and allow firmware
  restart after update-check errors.

## Limits

PC Transporter remains a test mode. See the
[setup and current limits](https://github.com/hasseily/appletini-one/blob/F1.3.7/README_PC_TRANSPORTER.md).

IIgs support remains experimental and off by default. Install Appletini in
physical slot 3 before enabling the profile, restart the card, and follow
[the IIgs setup and safety notes](https://github.com/hasseily/appletini-one/blob/F1.3.7/README_IIGS_SAFETY.md).
Each enabled virtual slot must be free of conflicting physical cards or
internal GS services.

ONE//e can still have one earlier key in the hardware latch when a new
key arrives. Keys from the same USB report stay in order.

## Build and validation

The release retains dev20's FPGA, matching XSA, FSBL, and CPU1 bytes.
CPU0 was rebuilt with the stable F1.3.7 version label. Source comparisons
against dev20 show no other content change after line-ending normalization.

- FPGA run: `20261118T193414Z-b63b74b4-full`.
- Setup WNS **+0.014 ns**, hold **+0.056 ns**, pulse width **+0.265 ns**.
- No failing timing endpoints; route, bus skew, and checked constraint
  bounds pass, with zero missing constraint objects.
- The retained run used a +0.000 ns export floor and a separate accepted
  +0.014 ns qualification. This is below the standard full-build helper's
  +0.050 ns setup gate. The original records remain unchanged.
- ONE//e input and configuration-menu regressions pass. The image audit
  verifies the loaded ARM bytes, FPGA configuration, embedded CPU1 payload,
  firmware version, manifest, and memory reservations.
- The user accepted dev20 for release. The dev19 display confirmation
  applies to the same retained FPGA image.

## Update

Install `FIRMWARE.BIN` through the normal firmware updater, or use
**About > Check for updates** with working Ethernet and SD storage.
Golden Boot **B2.0.6** is unchanged. Cards already using B2.0.6 need only
the firmware update. [Update instructions](https://github.com/hasseily/appletini-one/blob/F1.3.7/README_BOOT_UPDATE.md)
