# Firmware F1.3.7dev15 — experimental Apple IIgs support

This prerelease adds an opt-in IIgs profile for Appletini installed in
**physical slot 3**. It enables virtual cards through slot I/O and
card-local memory while keeping host `/INH`, `/DMA`, address/RW driving,
acceleration, and host-memory replacement blocked.

It also adds experimental native GS video capture through slot 3's M2B0
signal, SHR rendering, GS colors and borders, and ordered video changes
within a frame. **This image has not been tested on an Apple IIgs board.**

## Setup

1. Install the attached `FIRMWARE.BIN` through the normal SD-card firmware
   update process.
2. With Appletini in physical slot 3, enable **IIgs physical slot 3 (after
   restart)** in Appletini's settings, or save `host.iigs.slot3=on` in its
   configuration. Restart Appletini to apply it.
3. Leave GS slot 3 on its internal 80-column setting. Set each reserved
   logical slot to **Your Card** in the IIgs Control Panel and leave those
   physical slots free of conflicting cards. SmartPort stays in logical
   slot 7. **On ROM 1, leave slot 4 internal to retain the native mouse.**

The slot-3 profile is off by default. The existing physical-slot-7 profile
remains available. Retest SmartPort boot, reads and writes before testing
other virtual cards or native video.

## Validation and limits

- Uses the exact selected m350 FPGA build, run
  `20261111T110934Z-2d5a594a-full`. Publication did not rebuild it.
- Setup WNS **+0.051 ns**, passing that build's **+0.050 ns** gate. This
  falls short of the earlier +0.200 ns release target.
- Hold slack +0.043 ns; pulse-width slack +0.265 ns; no failing endpoints.
  Route, bus skew and checked constraint bounds passed.
- Fresh matching ARM platform, FSBL, CPU0 and CPU1 build passed. The package
  audit verified the FPGA payload, ELF load bytes, embedded CPU1 image,
  version and recovery footer.
- All 11 IIgs simulation benches and 1,272,185 SmartPort routing checks
  passed. Relevant firmware policy, Phasor and renderer checks passed.
- Native video still needs physical M2B0/timing and throughput tests.
  GS alternate character-ROM maps and legacy linear-address behavior
  remain incomplete or unverified. Phase recovery may need another
  observed counter-read sequence; lost memory writes need a host redraw.

See the tagged [setup and safety notes](https://github.com/hasseily/appletini-one/blob/F1.3.7dev15/README_IIGS_SAFETY.md)
and [validation record](https://github.com/hasseily/appletini-one/blob/F1.3.7dev15/README_IIGS_VALIDATION.md)
for feature details and pending board checks.
