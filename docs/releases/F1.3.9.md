# Firmware F1.3.9

F1.3.9 adds the ONEWWW web browser and a new FTP server.

## Changes

- **ONEWWW web browser.** The card gets each web page, lays it out, draws it
  and sends the picture to its HDMI output at 640 x 400 in true colour. The
  Apple program sends the keys and the mouse. It runs on an Apple II+ and an
  Apple //e.
  - Layout with blocks, lists, tables, floats and flex rows.
  - Style sheets with the cascade, selectors and custom properties.
  - PNG, JPEG and GIF pictures in full colour.
  - Forms with GET and POST, and cookies while the browser is open.
  - Proportional fonts with smooth edges: Latin, Greek and Cyrillic.
  [ONEWWW guide](https://github.com/hasseily/appletini-one/blob/F1.3.9/README_ONEWWW.md)
- **FTP sharing for more clients.**
  - Three clients can connect at one time. FileZilla and other clients that
    open more than one connection now work.
  - Active mode (`PORT`, `EPRT`) is supported. The Windows `ftp` client now
    works.
  - A stopped transfer can continue (`REST`, `APPE`).
  - Uploads are faster: 1.4 MB/s (before: 300 kB/s). Downloads are faster:
    1.3 MB/s (before: 900 kB/s). These are measurements with one client on
    a local network.
  - A fast transfer can no longer lose its "transfer complete" reply.

## Limits

- ONEWWW needs the disk `ONEWWW.po` from Appletini Software 1.3.9 and a
  display on the HDMI output of the card.
- ONEWWW does not run JavaScript. CSS grid, positioned boxes, WebP and SVG
  are not supported. The cookies are gone when the browser closes.
- The Apple IIgs has no ONEWWW client program yet.
- The JPEG and GIF decoder (`stb_image`) is not hardened against malformed
  files from a web site.
- FTP: the network chip has four sockets. With three clients, only one
  transfer runs at a time and the others wait. A fourth client is refused.
  FTP sends file data without encryption.
- IIgs support remains experimental and off by default, as in F1.3.8.
  [IIgs setup and safety notes](https://github.com/hasseily/appletini-one/blob/F1.3.9/README_IIGS_SAFETY.md)

## Build and validation

The FPGA image is that of F1.3.8, run `20261120T190553Z-fea5c6e9-full`. The
FPGA sources and the CPU1 sources are the same as in F1.3.8. Only the CPU0
program has new code.

- The image audit verifies the loaded ARM bytes, the FPGA configuration,
  the embedded CPU1 payload, the firmware version and the manifest.
- The source checks of the FTP server and the PC render check of the
  ONEWWW home page pass.
- The development image F1.3.9dev22 was tested on a card: ONEWWW with its
  home page and web sites, and FTP with FileZilla and the Windows `ftp`
  client. A 32 MB file had the same SHA-256 after an FTP transfer.
- F1.3.9 has the same sources as F1.3.9dev22, with the version text
  changed. This note records no board test of the final image.

## Update

Install `FIRMWARE.BIN` through the normal firmware updater, or use
**About > Check for updates** with working Ethernet and SD storage.
Golden Boot **B2.0.6** is unchanged. Cards already using B2.0.6 need only
the firmware update. [Update instructions](https://github.com/hasseily/appletini-one/blob/F1.3.9/README_BOOT_UPDATE.md)
