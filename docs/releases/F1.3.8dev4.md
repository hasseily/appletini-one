# Firmware F1.3.8dev4 — catalog progress in percent

This development build changes one text of the CoGS game browser. It
contains everything in [F1.3.8dev3](F1.3.8dev3.md), with the same FPGA
image.

## CoGS browser

- **Catalog load.** The screen shows `Loading games: 47%` while the catalog
  loads. Before, it showed `Loading catalog page 17 of 36`. Those were the
  pages of the provider's full list. The browser keeps only a part of that
  list, so the numbers did not agree with the pages that the user sees
  later.
- **Page numbers.** When the load is complete, the footer shows
  `Page 1 of N`, where N is the page count of the filtered list, 20 games
  for each page. This part did not change.

The percentage is the share of the provider's pages that the card has
received. It goes up in steps: with 36 pages, about 3% for each step.

## Build and validation

Only the ARM code changes. This package uses the FPGA build
`20261120T190553Z-fea5c6e9-full` of F1.3.8dev1 again. Packaging does not
rebuild the FPGA.

- Setup WNS **+0.160 ns**, hold **+0.047 ns**, pulse width **+0.265 ns**.
- No failing endpoints. Route, bus skew, and checked constraint bounds
  pass, with zero missing constraint objects.
- The run used a +0.000 ns export gate. The package check requires
  +0.020 ns.

Checks:

- `test_cogs_service.py` checks the text at 0%, 25%, 50% and 75% of a
  four-page catalog, and that the page number stays 0 during the load.
- `test_cogs_menu.py` checks that the footer shows no page number during
  the load and shows `Page n of N` when the list is ready.

The package contains a new XSA-derived platform, FSBL, and both ARM
cores. Golden Boot stays at **B2.0.6**. This package has no Golden update.

## Hardware test

Nobody has flashed or tested this image on a card. Install `FIRMWARE.BIN`
through the normal firmware updater.

- CoGS: open **Ethernet > CoGS games** after a reboot. The percentage must
  go from 0% to the game list, and the footer must then show the page
  count of that list.
- The tests of F1.3.8dev1, F1.3.8dev2 and F1.3.8dev3 still apply.
