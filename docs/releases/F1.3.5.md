# Firmware F1.3.5 test builds

These ARM-only test builds led to the published [F1.3.6 release](F1.3.6.md),
which also rebuilds the FPGA, FSBL, BSPs and CPU1.

F1.3.5 adds stable GitHub update checks to the configuration menu. About shows
an update badge and separate installed/available firmware and Golden boot
versions. Its update buttons download `FIRMWARE.BIN` or `BOOT.BIN` directly
from the latest stable Appletini release, verify the download, and use the
existing installers after confirmation. Drafts and prereleases are excluded.

The check runs automatically in the initial boot menu or an isolated ONE//e
menu; About also has a manual check. Firmware and boot versions are compared
separately, and the boot version comes from the verified image. The updater
checks HTTPS, the release asset's size and SHA-256, the image's manifest and
product, and its linked stable version before publishing a complete SD file.
Downloads can be cancelled. Existing root update files are preserved.

The updater lets the shared HTTP builder add `Accept-Encoding: identity`;
supplying that reserved header a second time previously stopped the request
with error `-1`. About now keeps the failed step and specific error visible,
including available HTTP, TLS, image-validation and SD details. File-cleanup
errors no longer replace the original cause.

About restores the Project Origin credit and places the open-source statement
below the third-party heading, with wider section gaps and a right-aligned
signature above the credit list. Credits wrap and scroll with the keyboard or
gamepad, so the full acknowledgment list remains reachable as it grows.

Online transfers use 4 KiB network reads, a 128 KiB ARM HTTP ring, and a
separate 128 KiB SD buffer. The updater batches full SD writes, pumps the
network between foreground tasks, and limits progress redraws to 10 Hz.
Input and error changes still refresh at once. The progress view shows elapsed
time and average KiB/s. During its exclusive Ethernet use, the updater gives
the W5100S TCP socket 8 KiB of receive memory and enables immediate ACKs;
it restores the normal socket layout before returning Ethernet to the Apple.

Profile fixes in these test builds:

- USB keyboards can type in Save As, Rename, and printout name editors,
  including ONE//e. Enter saves, Backspace deletes, and Esc cancels.
- Gamepad Y / Triangle shows or hides the on-screen keyboard. The bottom
  bar shows the current controls, and USB typing works with either view.
- Profiles save and restore the ONE//e PAL/NTSC standard. Old profiles without
  this key default to NTSC; choose PAL and save them again when needed.
  A running session applies a new standard at its next virtual reset or restart.

Install `FIRMWARE.BIN` through the normal SD updater. Golden B2.0.6 and the
released FPGA image remain unchanged. See [update instructions](../../README_BOOT_UPDATE.md).

Native update, image-validation, menu, profile and installer-failure tests
cover the changes. The package audit verifies the CPU0 image, retained CPU1,
FPGA/XSA and boot inputs. Firmware download throughput has been confirmed on
hardware; the revised About layout still needs a board test.
