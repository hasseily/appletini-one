# Firmware F1.3.8dev7 — images inline, at the size of the page

This development build changes the page service for the TINIBROWSER web
browser. It contains everything in [F1.3.8dev6](F1.3.8dev6.md), with the
same FPGA image.

## Page service

- **Inline images.** The filter no longer puts a line break before and
  after each image. An image stays where the page has it: in a line of
  text, in a link, or alone in its block.
- **Display size.** When the page gives `width` or `height` in pixels,
  the image tag carries them as `w=N` and `h=N`. Values in percent, zero
  and values above 9999 are left out.

TINIBROWSER of the same date uses both. It puts a picture in the text
flow at the current column, with the text on its right, and it asks the
card for a picture of the display size (at most 546 x 240 pixels). An
older TINIBROWSER with this firmware shows each image on its own line as
before, because its layout does that itself.

Limits:

- Sizes that come from CSS are not known: the card does not read style
  sheets. Such an image shows at its natural size, at most 546 x 240.
- One page pixel is one screen pixel. The browser does not scale a page
  that was made for a wider screen.
- Text after a picture continues on the last text row of the picture.
  Text before it stays on the first row.

## Build and validation

Only the ARM code changes. This package uses the FPGA build
`20261120T190553Z-fea5c6e9-full` of F1.3.8dev1 again. Packaging does not
rebuild the FPGA.

- Setup WNS **+0.160 ns**, hold **+0.047 ns**, pulse width **+0.265 ns**.
- No failing endpoints. Route, bus skew, and checked constraint bounds
  pass, with zero missing constraint objects.
- The run used a +0.000 ns export gate. The package check requires
  +0.020 ns.

Checks:

- `test_net_page.py` has a new case for an image in a line of text with
  sizes in pixels, with a `px` suffix, in percent and with a leading zero.
- `test_net_service.py`, `test_net_image.py` and
  `test_online_update_main.py` pass as for dev6.
- The TINIBROWSER test `mono_inline.py` runs the 6502 program: the box
  that the browser asks for, the text to the right of a picture, and the
  wrap of a picture that does not fit in the line.

The package contains a new XSA-derived platform, FSBL, and both ARM
cores. Golden Boot stays at **B2.0.6**. This package has no Golden update.

## Hardware test

Nobody has flashed or tested this image on a card. Install `FIRMWARE.BIN`
through the normal firmware updater, and use the TINIBROWSER disk of the
same date.

- Open `https://appletini.org`: the wordmark and the board picture show in
  the flow of the page, and small pictures stand in their line of text.
- Open a page with icons in its text: each icon has the size that the page
  gives, and the text continues on its right.
- The tests of F1.3.8dev1 to F1.3.8dev6 still apply.
