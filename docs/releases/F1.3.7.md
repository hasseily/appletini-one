# Firmware F1.3.7

F1.3.7 adds PC Transporter test mode in virtual slot 5. The mode includes
shared RAM, Portware I/O, CGA output, USB keyboard input and UART status.
The menu can select Appli-Card, AD8088 or PC Transporter.

The firmware uses the selected FPGA run `20261107T033658Z-34f07ced-full`.
Its final setup slack is +0.068 ns, hold slack is +0.024 ns and pulse-width
slack is +0.265 ns. The run passed the standard timing checks and exported
an XSA. It used a 0.215 ns margin during implementation.

Three test suites had old source checks. The boot menu suite now checks
all three close handlers. The SDD suite accepts the joystick settings row.
The ONE//e video suite checks DVI timing for each preset. All three pass.

Vitis built the FSBL, BSPs and both ARM cores from the selected XSA. The
package audit passed for the FPGA data, FSBL, CPU0 and embedded CPU1.
The firmware manifest and CRC checks passed.

The `FIRMWARE.BIN` test image is 4,889,260 bytes. Its SHA-256 is
`2bc1612de4e78034b286aa4f41a7600f68c076dcbd57490507629bfc359ef9c9`.
This image still needs a board test.

PC Transporter still needs connector timing tests and a complete DOS boot
on the board. Pointer wrap and word I/O rules need an original-card trace.
TransDrive, the NEC `0Fh` group and CGA retrace status remain open.

This build uses Golden B2.0.6. Install the test firmware through the normal
firmware update action. [Update instructions](../../README_BOOT_UPDATE.md)
