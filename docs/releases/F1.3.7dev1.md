# Firmware F1.3.7dev1

This development build fixes SmartPort character reads. The slot ROM now
copies the number of bytes reported by the service and returns that count in
X/Y. The firmware still rejects character reads for unsupported devices.

The firmware identifies itself as F1.3.7dev1. The online updater accepts
development versions as the installed firmware version and continues to
offer stable releases.

CoGS shows standalone 8-bit games, skips catalog pages with no eligible
entries, and fits all game rows on screen without scrolling.
