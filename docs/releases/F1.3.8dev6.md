# Firmware F1.3.8dev6 — the card filters web pages and forms

This development build adds a page service for Apple programs. The
TINIBROWSER web browser (before: A2MONO) uses it. It contains everything
in [F1.3.8dev5](F1.3.8dev5.md), with the same FPGA image.

## Page service

Until now the browser kept the first 64 KiB of the raw HTML and parsed it
on the 6502. On most sites that part holds only `<head>`, scripts and
styles, so the page was empty or cut. Now the card reads the page.

- **Request.** An Apple program sets the new PAGE flag in a START command.
  Capability bit `$40` of the descriptor reports the service. The flag
  works with the automatic download decision and with any method.
- **Input.** Up to 4 MiB of HTML. A response that is not HTML streams to
  the Apple as before.
- **Output.** A short page in 7-bit ASCII, at most 65,535 bytes, with only
  headings, paragraphs, line breaks, list items, links and images.
- **Removed.** `<head>`, scripts, styles, comments, SVG, frames, and
  elements that are hidden. A `<head>` without an end tag, and quotes or
  `</` inside a script, cannot hide the page.
- **Text.** UTF-8 or Latin-1 text and all entities become ASCII: `é`
  becomes `e`, a long dash becomes `--`. Other scripts show as `?`.
- **Images.** The image tag gets the real URL: `src`, a lazy-load
  attribute, or the first `srcset` entry. Tracking pixels and SVG files
  are dropped; the `alt` text shows in their place.
- **Anchors.** Only the targets of same-page links keep their `id`.
- **Forms.** Each form becomes one link, `[Form: name, ...]` or
  `[Send form]`. The link URL holds the fixed fields (hidden fields,
  checked boxes, the selected option) and `%s` for each field that the
  user must type. A POST form has the URL `post:` + action + one space +
  body. The browser asks for each typed field and sends the request.

Measured on a PC with pages fetched on 21 November 2026:

| Page | Raw HTML | Filtered |
|---|---|---|
| google.com | 93,667 bytes | 1,660 bytes, with the search form |
| appletini.org | 12,184 bytes | 6,503 bytes |
| github.com | 537,320 bytes | 16,478 bytes |
| en.wikipedia.org/wiki/Apple_II | 369,976 bytes | cut at 65,535 bytes |

`README_HTTP_SMARTPORT_PROTOCOL.md` has the protocol.

Limits:

- The firmware keeps no cookies. A login form sends its data, but the
  site does not see the next request as logged in.
- A form link has at most 232 characters. A form with more data than that
  shows no link.
- JavaScript does not run. Google search results need JavaScript; a search
  site that works without it (for example `html.duckduckgo.com/html`) is a
  better choice.
- The card filters a page in one step in its main loop, as it decodes an
  image. Nobody has measured this time on a card.

## Build and validation

Only the ARM code changes. This package uses the FPGA build
`20261120T190553Z-fea5c6e9-full` of F1.3.8dev1 again. Packaging does not
rebuild the FPGA.

- Setup WNS **+0.160 ns**, hold **+0.047 ns**, pulse width **+0.265 ns**.
- No failing endpoints. Route, bus skew, and checked constraint bounds
  pass, with zero missing constraint objects.
- The run used a +0.000 ns export gate. The package check requires
  +0.020 ns.

Checks:

- `test_net_page.py` runs the filter on a PC: head and scripts, blocks,
  ASCII text, links, anchors, images, hidden parts, GET and POST forms,
  unfinished input and the output limit.
- `test_net_service.py` runs the protocol: a filtered page read by offset,
  a plain stream for other content types, the flag rules and a POST.
- `test_net_image.py` and `test_online_update_main.py` pass as for dev5.
- The TINIBROWSER tests (in the appletini-software repository) run the
  6502 program against a model of the card: pictures, form links with GET
  and POST, and the older page tests.

The package contains a new XSA-derived platform, FSBL, and both ARM
cores. Golden Boot stays at **B2.0.6**. This package has no Golden update.

## Hardware test

Nobody has flashed or tested this image on a card. Install `FIRMWARE.BIN`
through the normal firmware updater, and use the TINIBROWSER disk of the
same date.

- Open `https://appletini.org`: the pictures load without a key press, and
  a scroll does not load them again.
- Open `https://www.google.com`: the page shows links and `[Form: q]`.
- Open `https://html.duckduckgo.com/html`, follow `[Form: q]`, type a
  search, and check that results show.
- Open a long article (for example Wikipedia): the text must show, with a
  cut note at the end if it is too long.
- STARFALL rankings do not use the new flags and must work as before.
- The tests of F1.3.8dev1 to F1.3.8dev5 still apply.
