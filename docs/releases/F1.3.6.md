# Firmware F1.3.6

F1.3.6 is published.

F1.3.6 includes a fresh FPGA build with the committed status-path timing
changes from `a862492`. ONE//e activity and inhibit readback use synchronized
signals, and the vTW posted-write ready diagnostic is registered. The live
bus acceptance and isolation paths keep their existing behavior.

The ARM firmware includes stable GitHub update checks, faster HTTPS downloads,
persistent update errors, USB/gamepad text entry, and profile PAL/NTSC settings
from the F1.3.5 test builds. About has wrapped, scrollable credits, wider
section gaps, and a right-aligned signature.

The release uses one full Vivado build and fresh XSA-derived FSBL, BSPs,
CPU0 and CPU1 builds. The existing known-good FPGA reference was not promoted.

The full Vivado 2025.2 run `20261030T164234Z-a8624920-full` passed at the
nominal constraints: setup slack +0.091 ns, hold slack +0.015 ns, and
pulse-width slack +0.265 ns. There are no failing timing endpoints or route
errors, and the bus-skew and constraint checks passed. Timing repeatability
across multiple builds was not checked.

The published `FIRMWARE.BIN` is 4,799,340 bytes, with SHA-256
`497f3d288da4a2c628ea8c5aa32ed6ca29a1b49b078809d70f44de1c460034c1`.
The image audit verified the FPGA configuration, FSBL and CPU0 load bytes,
the embedded CPU1 binary, both generated platform XSAs, and the frontend's
64 KiB stack and 64 MiB heap. Native menu, updater and build checks passed.

Install `FIRMWARE.BIN` through the normal SD updater. Golden B2.0.6 remains
compatible; this version does not require a new `BOOT.BIN`. See the
[update instructions](../../README_BOOT_UPDATE.md).
